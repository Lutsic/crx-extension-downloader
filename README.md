## **CRX Extension Downloader**

**CRX Extension Downloader** is a lightweight and efficient tool designed to download Chrome and Firefox extensions without official stores.

### **🌟 Key Features**

* **Zero Installation:** Core functionality built entirely with HTML and JavaScript. It runs as a website or a local file in any web browser.  
* **Bypass Restrictions:** Specifically designed for school Chromebooks and restricted environments where the Chrome Web Store is blocked and software installation is disabled.  
* **Portable & Secure:** No admin rights or external dependencies are required for the core functionality.  
* **Toolkits:** Includes toolkit writed on Python for work with extensions, if Python installation is possible. And also a lite version of the toolkit, which can run on online python compilers.

### **🚀 How to Use**

#### **1\. Core Functionality (Web or Local)**

* **Web Version:** Open the [website](https://lutsic.github.io/crx-extension-downloader) linked to this repository.  
* **Local Use:** Download the repository and open `index.html` in your browser. No installation or server required.

#### **2\. Global Search**

Search through a database of over **250,000** chrome extensions.

* Enable the **"Global Search"** checkbox below the search box.  
* **Note:** The search targets the extension's slug (the name used in the Chrome Web Store URL). It may slightly differ from the display name.

#### **3\. Python Toolkit (Full Version)**

1. Download the repository and open the `python_tools` folder.  
2. **Install Dependencies:**  
   * **Windows:** Run `install_requirements.bat`.  
   * **macOS / Linux:** Open your terminal in the folder and run: `pip install \-r requirements.txt`
3. Launch the toolkit script.

#### **4\. Python Toolkit (Lite Version)**

Quick execution without local environment setup.

1. Copy the source code from the Lite version file.  
2. Paste it into an online Python compiler like [Programiz](https://www.programiz.com/python-programming/online-compiler/) or [OnlineGDB](https://www.onlinegdb.com/online_python_compiler).  
3. Run the script instantly.
